# Changelog

## 0.1.0

- First release. STL (binary and ASCII), OBJ with MTL and textures, PLY, 3MF, GLB and glTF viewer.
- Orbit, pan and zoom, wireframe, normals, grid, axes, bounding box in millimetres, triangle and vertex counts, measuring, animations, scene tree.
- PNG screenshot through the IDE save dialog.
- Range reads: a 200 MB binary STL opens without freezing the IDE.
- Without WebGL: file facts from Kotlin (triangle count from the STL header) and Open in Default App.
